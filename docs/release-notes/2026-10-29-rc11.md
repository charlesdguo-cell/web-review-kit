# rc.11: default global installation

Installing the complete Web Review Kit bundle now selects its verified runtime as the global default. `--activate-global` remains accepted; `--no-activate-global` installs files without changing the selection. Supply `--skill-link` to create or update the global discovery entry. Existing unmanaged links or directories are preserved and reported as conflicts.

Projects can use `toolVersion: global` to follow the selected runtime, while explicit version pins continue to work. New project setup through the installed global helper defaults to `global`; existing configurations are preserved. Projects keep their own configuration, review data and task history. Global installation does not migrate data, restart services, dispatch tasks or edit global Codex settings.

Services and tasks retain their concrete runtime version. Frozen worker requests and their build commands keep that version after the global default changes. Historical requests whose project identity or version policy no longer matches fail explicitly without rewriting their records. Keep older installed versions while they are still needed.

This release includes the global-runtime work previously installed locally as rc.10. That local bundle stays unchanged; rc.10 was not remotely published. Historical rc.1–rc.9 bundles remain valid for explicit pins and require `--no-activate-global` when installed with the new installer.

Install the complete archive using its own installer and the [release guide](https://github.com/charlesdguo-cell/web-review-kit/blob/v0.1.0-rc.11/docs/releases.md). The release assets are the archive, SHA-256 file and closed manifest; copying only `SKILL.md` does not install the runtime. Formal platform validation remains macOS with Python 3.9+. No consumer deployment or real model task is part of this release validation.

Validation passed on the final release source: **214 Python discovery tests**, including synthetic Codex and annotation browser fixtures; **29 review + 13 attachment + 9 shared-review browser checks**; and Skill metadata validation. Independent code review found no blocking issue. The focused global/release suite also passed **48 tests**.

Two package builds were byte-identical. Isolated installation using the package's own installer verified default activation, stable global Skill discovery, repeated installation, explicit opt-out, new-project global configuration and preserved existing configuration without starting a service or task. The closed manifest matches all 32 managed source files.
