# Web Review Kit 0.1.0-rc.7

Published private prerelease: [v0.1.0-rc.7](https://github.com/charlesdguo-cell/web-review-kit/releases/tag/v0.1.0-rc.7). Runtime source and tag: `f25f132e4144c14a9e30049c59365b17d2533dfa`, branch `feat/portable-review`.

Static media responses now stream in 64 KiB chunks. HEAD does not read the body; valid byte ranges retain seeking behavior, malformed ranges retain their previous full-response fallback, and cancelled media requests are handled without retaining entire files. This ports the already deployed Morsea fix back to the toolkit's unique runtime source.

Validation: 146 independent tests, 29 review browser checks, 13 attachment checks and 9 shared-review checks passed. The concurrent-media regression uses 16 requests against a synthetic 64 MiB asset. The complete installed package also passed Morsea's isolated Linux container preflight with a 256 MiB limit, read-only root, no network and temporary review data; all 48 media checks passed with 28.63 MiB peak RSS.

The published archive was downloaded again and matched the local verified installation byte for byte: SHA-256 `03c8a6df7ff210ffd7856a2a781718edbeec8049bfa30b1183b275a91f0c9234`. Runtime, frontend assets, Skill and manifest remain one 32-file bundle. The existing global Skill link now points to the installed rc.7 bundle. Existing project pins and running local services were preserved; Morsea's local pin remains rc.3 while its team release uses the complete rc.7 package.

Morsea deployed `marketing-workflow-20261027T182324Z`, build `065c70e5cdd1`, with the original 256 MiB memory limit, HTTPS prefix and Codex disabled. All 7 team comments and their 7 screenshots were preserved. This is validation of that specific team deployment, not a general Linux installer or cross-platform acceptance claim. Consumer deployment and browser evidence is recorded in [Morsea's release record](https://github.com/charlesdguo-cell/morsea-prototype/tree/main/research/2026-10-28-prototype-deployment).
